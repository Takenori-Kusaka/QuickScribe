# GTK3-rs 依存関係スイープおよび追跡記録 (Issue #686 / ADR-0034)

> Status: Tracking
> 再評価期限: 2026-10-31 (ADR-0034 / #686)

## 1. 概要

Tauri 2.x は、Linux 上での Webview レンダリング（Webkit2GTK）およびシステムトレイ・ウィンドウランタイムの基礎として、GTK3（`gtk` 開発系）を利用しています。これに伴い、以下の `gtk-rs` 由来の GTK3 関連バインディングライブラリ（計10件）が過渡的に導入されます。

現在、上流の `gtk-rs` プロジェクトは主要なメンテナンス対象を GTK4 へ移行しており、GTK3 関連のバインディング（0.18系以下）は **unmaintained（非推奨・未メンテナンス）** に指定され、RUSTSEC データベースに警告が登録されています。また、`glib` については特定の soundness（健全性）に関する警告（RUSTSEC-2024-0429）が報告されています。

本書は、Tauri を利用する以上不可避であるこれらの未メンテナンスおよび健全性警告を、一括して追跡・管理するための合意済みのドキュメント（SSOT）です。

## 3. 回避不可能性の検証

1. **Tauri による依存ロック:**
   `cargo tree -i glib` が示すように、これらの crate はすべて `tauri-utils` / `tauri-runtime-wry` が直接、または推移的に依存しており、アプリケーション側で個別にバージョンを動かしたり、除外したりすることはできません。
2. **上流の移行時期:**
   Tauri 3.x（GTK4 への公式移行）がリリースされ、そちらへアプリケーションを移行するまでは、この GTK3 由来の未メンテナンス警告を恒久的に受容する必要があります。

## 4. 運用とライフサイクル

- **ホワイトリスト管理:**
  本書に記載された 11 件の警告 ID は、`src-tauri/deny.toml` および `src-tauri/.cargo/audit.toml` の `ignore` リストに記載されています。
- **再評価のトリガー:**
  再評価期限は **2026-10-31** です。この期限を超えた場合、セキュリティの定期スイープにおいて、Tauri の最新バージョンにこれらが解決されたアップグレードが含まれていないかを再調査します。
