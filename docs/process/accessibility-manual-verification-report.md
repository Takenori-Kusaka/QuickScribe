# スクリーンリーダー手動検証実施記録（NVDA / ナレーター検証） (Issue #565 / #395 / #481)

> Status: Completed / Verified (2026-08-17)
> 検証環境: Windows 11 Home + NVDA 2026.1 / Windows ナレーター
> 対象バージョン: v1.10.0 以降（Tauri WebView2 環境）

## 1. 検証の背景と目的

QuickScribe は [ADR-0006](../adr/0006-scope-completeness-policy.md)（スコープ完全性）および [ADR-0010](../adr/0010-v0.1.0-gate-legal-must-only.md)、[#395](https://github.com/Takenori-Kusaka/QuickScribe/issues/395) に基づき、WCAG 2.1 AA / JIS X 8341-3:2016 レベルのアクセシビリティ（a11y）準拠を目指しています。

`e2e/a11y.spec.ts` における axe による自動アクセシビリティスキャンは PR ゲートとして常時グリーンを維持していますが、自動スキャンのみでは Tauri WebView2（Edge Chromium 描画エンジン）実環境における「実際の読み上げ順の自然さ」「状態変化時の音声通知（`aria-live`）」「フォーカストラップの実挙動」を完全には担保できません。

本書は、人手（手動）によるスクリーンリーダー（NVDA / Windows ナレーター）検証の結果および適合性エビデンスを記録するものです。

---

## 2. 検証項目と適合性エビデンス

### 2.1. メイン画面：録音開始／停止操作と状態遷移
- **検証方法:** 
  - メイン画面を起動後、Tabキーで録音ボタンへ移動し、スペースキーまたはエンターキーで録音の開始・停止を操作。
- **実挙動と読み上げ内容:**
  - 録音ボタンのフォーカス時、ボタンのラベル（「録音開始」等）およびショートカットキー案内が正確に読み上げられます。
  - 録音開始時、`aria-live="polite"`（ポライト・ライブ領域）に配置された「録音中...」の状態変化が、操作の邪魔をすることなく適切なタイミングで読み上げられます。
  - 録音停止時、文字起こしジョブがキューに追加された旨が「処理中 1 件（またはジョブ追加）」として音声通知されることを確認しました。

### 2.2. 設定モーダル（設定ダイアログ）
- **検証方法:**
  - ヘッダーの設定アイコン（ボタン）を起動し、ダイアログ内に入りフォーカス動作を検証。
- **実挙動と読み上げ内容:**
  - ダイアログ起動時、`role="dialog"` および `aria-modal="true"`、`aria-labelledby` が正常に機能し、「設定 ダイアログ」として境界が宣言されます。
  - **フォーカストラップ（Focus Trap）の動作:** Tabキーを押し続けても、フォーカスが設定モーダルの外部（背後のメイン画面）に漏れず、ダイアログ内のコントロール間（キャンセル、保存、各入力項目）をループすることを確認しました。
  - **エスケープキー（Esc）閉じ:** Escキーを押下した際、即座に設定ダイアログが閉じ、フォーカスが呼び出し元の設定ボタンへと正しく戻る（フォーカス復元）ことを確認しました。

### 2.3. ジャーナル（保管庫）一覧のナビゲーション
- **検証方法:**
  - キーボードの矢印キーおよび Tab キーで、保管庫内の過去エントリ一覧を移動。
- **実挙動と読み上げ内容:**
  - 保管庫の一覧領域が `<ul>` / `<li>` のセマンティックなリスト構造として認識され、スクリーンリーダー側から「リスト、N個の項目」と通知されます。
  - 各エントリ（WAV/Markdown等）の作成日時やラベルが自然な順序で遮られることなく読み上げられます。

### 2.4. 初回起動オンボーディング
- **検証方法:**
  - オンボーディング画面が表示されている状態で、最初から最後まで Tab キーで移動。
- **実挙動と読み上げ内容:**
  - オンボーディング表示中、背後のUIへのアクセスが完全に遮断され、オンボーディングダイアログ内の解説テキスト（「QuickScribe へようこそ」等）およびチュートリアルが順序よく正常に読み上げられます。

## 3. 結論と判定

- **総合判定:** **適合 ✅（手動アクセシビリティ検証合格）**
- **特記事項:** 
  - 手動検証において、読み上げ順の破綻、フォーカスの紛失（フォーカス・ブラックホール）、モーダル外部へのフォーカス漏れなどのアクセシビリティ上の致命的なバグは検出されませんでした。
